# 28 个开源仓库重构场景结果

按仓库、代码选区和重构目标去重。同一任务的正确或错误补丁、复跑和不同 Agent 模式共用一个场景。部分场景在固定上游检出的评测副本上增设了最小入口。

28 个场景均找到至少一次通过记录，其中提取 16 个、内联 6 个、移动 6 个。表中分母只计该场景所选评测批次的同题运行。各研究批次有各自的验收条件，表中次数适合用来查看单题证据。
